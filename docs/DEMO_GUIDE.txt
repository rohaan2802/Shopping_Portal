SHOPPING_PORTAL - DEMO AND PROJECT NOTES
=======================================

WHAT THIS PROJECT DOES
A C++17 shopping system. Admin manages inventory and reads inventory insights, Vendor manages
owned products, and Customer browses, builds a cart, saves a wishlist and places
orders. It demonstrates OOP role contracts, file persistence and validation.
It does not process real payments. Public demo passwords are not production auth.

THREE ENTRY POINTS
1. Windows console: actual file-backed role workflows.
2. Catalog CLI: portable read-only audit of product records.
3. Webpage: portfolio + independent browser simulation of customer shopping.
The browser does not call the console program or modify its text files.

BUILD FROM THE PROJECT ROOT
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure

For MinGW + Ninja, configure a fresh build directory with:
cmake -S . -B build -G Ninja -DCMAKE_CXX_COMPILER=g++ -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel 2
Do not mix CMake generators in the same build directory.

EXPLAIN THE METHOD
Prices become integer paisa (100 paisa = one PKR).
Subtotal = sum(price_paisa x quantity).
Tax and delivery are independently rounded half up at 5%.
Each charge = floor((subtotal x 500 + 5000) / 10000).
The C++ implementation splits quotient/remainder to avoid overflow.
Complete-line parsing preserves hyphenated names such as T-shirts.
Checkout validates the whole cart before writing, stages order and stock files,
and restores backups after ordinary in-process file errors.
This is not a database: no concurrent writers or power-loss durability.
Do not run two native copies against the same runtime directory.

LIMITATIONS TO MENTION HONESTLY
Public plaintext demo accounts, fixed console capacities, text files and a
single-process persistence model. Ambiguous name/price matches across categories
are rejected. The browser is a simulation. No real payment or shipping service.
The CMake + MinGW Windows build is the reference build; the portable CLI and
both C++ test suites also build with GCC on Linux.
