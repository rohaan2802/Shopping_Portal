# Preserved project history

Git history and the original `master` branch remain intact. Original HEAD: `86f654d`.

- `README_original.md`: original public documentation.
- `build_original.bat`, `run_original.bat`: original machine-specific launchers.
- `screenshots/`: 35 legacy images supplied by the original repository. They were made by its historical image-rendering script; they are not fresh execution evidence.
- `../../tools/history/generate_screenshots_original.py`: preserved original illustration generator; the current screenshots come from `tools/render_figures.py`.
- `../../data/legacy/`: byte-preserved original text data, including the original zero stock for Apples.
- `Classes_original.txt`: early design notes; the current class breakdown is in the main README.

The maintained seed is `data/sample`. Apples stock is reset to 20 for repeatable demonstrations; demo credentials remain explicitly non-production. Source files were moved, not discarded. Root object files, old executable copies and machine-path build artifacts were removed because source and build definitions reproduce them.
